# المصحف الشريف

تطبيق مصحف متكامل برواية حفص عن عاصم، بنص وخط مجمع الملك فهد لطباعة المصحف الشريف، وبصفحات مصحف المدينة النبوية (٦٠٤ صفحة).

## المميزات
- **القراءة:** صفحات المصحف بإطار مزخرف، والتقليب بالسحب، والتمرير التلقائي بـ ٨ سرعات، والانتقال لأي صفحة أو آية
- **الخطوط:** خط مجمع الملك فهد، وخط أميري، وخط شهرزاد، وكل خط بالنص المصمم له
- **التلاوة:** ١٤ قارئاً منهم الشيخ مصطفى إسماعيل، وتكرار الآية، والاستماع في الخلفية، وتحميل السور للاستماع بدون إنترنت
- **التفسير:** الميسر والسعدي بدون إنترنت، وابن كثير والطبري والقرطبي والبغوي أونلاين
- **معاني الكلمات:** الميسر في غريب القرآن
- **الترجمة:** Saheeh International
- **التسميع:** إخفاء الآيات وكشفها كلمة كلمة أو آية آية
- **الختمة:** خطة ختمة بعدد أيام تختاره، وورد يومي، وتذكير بالورد
- **الصلاة:** مواقيت الصلاة حسب موقعك (أم القرى وغيرها)، وتنبيه بالأذان، وبوصلة القبلة
- **الأذكار:** أذكار الصباح والمساء وبعد الصلاة والنوم والاستيقاظ والتسابيح، بعدّاد لكل ذكر وتذكير يومي
- **ويدجت** على الشاشة الرئيسية بآية اليوم وتقدم الورد
- الوضع الليلي، وتغيير حجم الخط، والبحث في القرآن كله

## تحميل التطبيق
حمّل أحدث نسخة `Mushaf.apk` من صفحة **Releases** في هذا المستودع.

## سلامة النص
نص المصحف هو نص مجمع الملك فهد (الإصدار ١٨) كما نشره المجمع، دون أي تعديل، ومعروض بخط المجمع الرسمي.
تمت مطابقته آلياً مع نسخة مستقلة من نص المجمع: كل الحروف والتشكيل في الـ ٦٢٣٦ آية متطابقة.

مع خطي أميري وشهرزاد يُستخدم النص العثماني من مشروع تنزيل (Tanzil Quran Text، رخصة CC BY 3.0) كما هو بالحرف، ومطابَق مع البصمة المنشورة للمصدر.

## البناء
يُبنى ملف APK تلقائياً عند كل رفع على فرع `main` عبر GitHub Actions.
- `web/` واجهة التطبيق والبيانات والخطوط
- `app/` غلاف أندرويد: تشغيل التلاوة، والتحميل، والتنبيهات، والموقع، والبوصلة، والويدجت
