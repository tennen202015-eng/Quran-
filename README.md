# المصحف الشريف

تطبيق مصحف كامل برواية حفص عن عاصم، بصفحات مصحف المدينة النبوية (٦٠٤ صفحة).

## المميزات
- قراءة بالصفحات مع إطار المصحف، والتقليب بالسحب
- فهرس السور والأجزاء، والانتقال لأي صفحة أو آية (مثل ٢:٢٥٥)
- التفسير الميسر وتفسير السعدي لكل آية
- الاستماع بأصوات ١٢ قارئاً، مع المتابعة التلقائية
- البحث في القرآن كله بدون تشكيل
- العلامات، والورد اليومي، وتقدم الختمة، وآية اليوم
- الوضع الليلي وتغيير حجم الخط
- يعمل بالكامل بدون إنترنت (عدا التلاوات)

## تحميل التطبيق
حمّل أحدث نسخة `Mushaf.apk` من صفحة **Releases** في هذا المستودع.

## سلامة النص
نص المصحف مأخوذ من مشروع تنزيل (Tanzil Quran Text، رخصة CC BY 3.0) كما هو بالحرف، دون أي تعديل.
تمت مطابقة الـ ٦٢٣٦ آية آلياً مع المصدر حرفاً بحرف.

## البناء
يُبنى ملف APK تلقائياً عند كل رفع على فرع `main` عبر GitHub Actions (`.github/workflows/build-apk.yml`).
- `web/` واجهة التطبيق والبيانات والخطوط
- `app/` غلاف أندرويد (WebView) يشغّل الواجهة من داخل التطبيق
